# 소개 페이지 스크린샷

`scripts/build-landing-page.mjs`가 이 디렉터리의 이미지를 그대로 복사해 소개 페이지의
"화면" 섹션에 늘어놓는다. **한 장도 없으면 그 섹션 자체를 만들지 않는다** — 자리만 잡힌 빈
섹션이 배포되지는 않으므로, 준비될 때 넣으면 된다.

- 확장자: `.png`, `.jpg`, `.jpeg`, `.webp` (나머지는 무시한다. 이 README도 그래서 안전하다)
- 순서: **파일 이름 순**이다. `01-map.png`, `02-claim.png`처럼 번호를 붙여 정한다.
- 크기: 세로로 긴 단말 화면을 전제로 높이 460px에 맞춰 보여준다. 원본은 실기기 해상도 그대로
  두어도 되지만, 한 장이 1MB를 넘으면 줄여서 넣는 편이 낫다(GitHub Pages로 그대로 나간다).
- 내용: 실제 앱 화면만 넣는다. 소개 페이지는 스토어·공모전 심사가 함께 보는 곳이라,
  구현되지 않은 화면의 목업이 섞이면 그대로 허위 기재가 된다.

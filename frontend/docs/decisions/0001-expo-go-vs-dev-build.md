# 0001. Expo Go vs Dev Build

## 배경

Expo Go는 별도 빌드 없이 QR 스캔만으로 즉시 실행할 수 있어 개발 초기 속도가 빠르지만, 네이티브 모듈이 필요한 기능은 지원하지 않는다.

| 기능 | Expo Go | Dev Build |
|------|---------|-----------|
| 화면 UI, 지도(WebView), 소켓 | O | O |
| 백그라운드 GPS 탐지 | X | O |
| 푸시 알림 | X | O |

## 결정

현재는 Expo Go로 개발하고, 지도·위치 작업을 시작하는 시점에 Dev Build로 전환한다.

## 이유

- 초기 화면/네비게이션/상태관리 작업은 네이티브 모듈이 필요 없어 Expo Go로 충분히 빠르게 반복 가능
- 백그라운드 GPS 탐지·푸시 알림은 Expo Go가 지원하지 않으므로, 해당 기능 작업 시점에만 Dev Build 세팅 비용을 지불

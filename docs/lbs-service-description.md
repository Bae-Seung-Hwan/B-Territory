## 2. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | B-Territory |
| 서비스 형태 | 모바일 애플리케이션 (Android / iOS) |
| 주요 이용자 | 부산을 방문하는 외국인 관광객 |
| 서비스 개시(예정)일 | (실제 출시일 기재) |

부산의 관광지를 직접 방문하면 해당 지점을 점령하고, 이용자의 국적별로 구성된 팀이 부산의 각 구(區)를 두고 경쟁하는 위치기반 관광 게임 서비스입니다.

관광객이 실제로 관광지를 찾아가도록 유도해 부산 지역 관광을 활성화하는 것이 서비스의 목적입니다. 관광지 정보는 한국관광공사가 제공하는 공공 API(TourAPI)를 기반으로 구성합니다.

## 3. 주요 기능

**관광지 방문 인증 (점령)** — 이용자가 관광지 근처에 도착해 인증을 요청하면, 해당 시점의 위치가 관광지 반경 내인지 서버가 검증합니다. 검증에 성공하면 그 관광지가 이용자의 팀 소유로 기록됩니다.

**구역 점령 경쟁** — 한 구(區) 안의 관광지를 많이 점령한 팀이 해당 구를 차지합니다. 점령 현황은 지도 위에 팀별로 표시됩니다.

**팀 구성** — 이용자의 국적을 기준으로 팀이 자동 배정됩니다.

**지도 표시** — 카카오맵을 통해 관광지 위치와 점령 현황을 표시합니다.

**부가 기능** — 팀별 순위, 명예의 전당, 관광지 관련 미션 등 게임 요소를 제공합니다.

## 4. 위치정보 이용 방식

### 4.1 수집하는 위치정보

| 구분 | 내용 |
|---|---|
| 수집 항목 | 이동통신단말장치의 GPS 좌표(위도·경도) |
| 수집 방법 | 이용자 단말의 위치 측위 기능 (앱 실행 중에 한함) |
| 수집 시점 | 앱이 화면에 표시되어 있는 동안에 한함 |

### 4.2 백그라운드 위치정보를 수집하지 않습니다

본 서비스는 **앱이 실행 중인 동안에만(포그라운드)** 위치정보를 이용합니다. 앱이 종료되거나 백그라운드로 전환되면 위치 수집이 즉시 중단됩니다. 단말 운영체제에 대해서도 포그라운드 위치 권한만 요청하며, 백그라운드 위치 권한은 요청하지 않습니다.

### 4.3 이용 목적

위치정보는 다음 두 가지 목적으로만 이용합니다.

1. **방문 인증** — 이용자가 관광지 반경 내에 실제로 있는지 확인
2. **지도 표시** — 이용자 주변의 관광지를 지도에 표시

### 4.4 보유 및 이용기간 — 위치정보를 저장하지 않습니다

본 서비스는 **개인위치정보를 데이터베이스에 저장하지 않습니다.**

방문 인증 시 전송된 좌표는 관광지 반경 내인지 판정하는 즉시 처리 과정에서만 사용되고 폐기되며, 별도로 기록되지 않습니다.

인증 성공 시 저장되는 정보는 다음과 같으며, **좌표값은 포함되지 않습니다.**

| 저장 항목 | 내용 |
|---|---|
| 관광지 식별자 | 어느 관광지가 점령되었는지 |
| 팀 | 어느 국가 팀이 점령했는지 |
| 이용자 식별자 | 누가 점령했는지 |
| 점령 시각 | 언제 점령되었는지 |

즉 "누가 언제 어느 관광지를 점령했다"는 게임 기록만 남고, 이용자의 이동 경로나 위치 이력은 생성되지 않습니다.

## 5. 위치정보 보호조치

**이용자 동의** — 앱 최초 실행 시 위치기반서비스 이용약관을 제시하고 동의를 받은 뒤에만 위치정보를 이용합니다. 동의하지 않아도 앱의 다른 기능은 이용할 수 있습니다.

**운영체제 권한** — 단말 운영체제의 위치 권한 요청 절차를 거치며, 이용자가 거부하면 위치정보를 일절 수집하지 않습니다. 권한은 앱 설정에서 언제든 철회할 수 있습니다.

**전송 구간 암호화** — 단말과 서버 간 모든 통신은 HTTPS(TLS)로 암호화합니다.

**접근 통제** — 서버 접근은 인증된 관리자로 제한하며, 이용자 인증은 Firebase Authentication을 통해 처리합니다.

**최소 수집 원칙** — 서비스 제공에 필요한 최소한의 위치정보만, 필요한 시점에만 이용하며, 이용 후 저장하지 않습니다.

## 6. 제3자 제공 및 위탁

**제3자 제공** — 개인위치정보를 제3자에게 제공하지 않습니다.

**지도 서비스** — 지도 화면 표시를 위해 카카오맵을 이용하나, 이용자의 위치정보를 카카오 측에 전달하지 않습니다. 지도 렌더링 용도로만 사용합니다.

## 7. 이용자 권리 보장

- 위치정보 이용에 대한 동의를 언제든지 철회할 수 있습니다.
- 위치정보 수집·이용에 대한 일시적 중지를 요구할 수 있습니다.
- 개인위치정보를 저장하지 않으므로 이용·제공 사실 확인자료가 생성되지 않으나, 관련 문의는 아래 연락처로 접수합니다.
- 법정대리인의 동의가 필요한 만 14세 미만 아동은 가입을 제한합니다.

## 작성 시 확인할 것

제출 전에 다음을 반드시 채우거나 검토하세요.

1. **괄호 표시된 항목 전부** — 상호, 대표자, 사업자등록번호, 소재지, 연락처, 출시일
2. **서비스 개시일** — 실제 앱 출시일 기준. 신고 기한(사업 개시 후 1개월)의 기산점입니다
3. **위치기반서비스 이용약관** — 5장에서 "약관 동의를 받는다"고 기술했으므로, 실제 약관이 앱에 준비되어 있어야 합니다
4. **만 14세 미만 제한** — 7장에 기재했으나 현재 가입 화면에 연령 확인 필드가 없습니다. 문구를 유지하려면 구현이 필요합니다

## 나중에 변경신고가 필요한 시점

이 문서는 **위치정보를 저장하지 않는다**는 점을 핵심으로 기술했습니다. 다음 기능을 구현하면 사실관계가 달라지므로 변경신고와 약관 개정이 필요합니다.

- 백그라운드 위치 추적
- 사진 촬영·인증 (사진에 위치 메타데이터가 포함될 수 있음)
- 위치 이력 저장이 필요한 기능

관련 배경은 [필요 법적 문서 / 약관 정리](./compliance.md)를 참고하세요.

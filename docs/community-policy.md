# 커뮤니티 운영정책

B-Territory의 팀 채팅 등 이용자 생성 콘텐츠(UGC)에 적용되는 정책이다.

Apple 심사 가이드라인 **1.2 (User-Generated Content)** 는 UGC를 다루는 앱에 네 가지를 요구한다. 이 문서와 구현이 각 항목에 어떻게 대응하는지 함께 적는다.

| 요구 사항 | 대응 |
|---|---|
| 불쾌한 콘텐츠를 걸러내는 방법 | 팀 채팅은 **같은 국가 팀원 간에만** 오간다(불특정 다수 공개 채팅 아님). 아래 금지 행위 + 신고 기반 사후 조치 |
| 신고 기능 + 적시 대응 | `POST /api/reports` — 메시지 원문 스냅샷과 함께 접수 |
| 악성 사용자 차단 | `POST /api/blocks/:userId` — **서버에서 릴레이를 끊는다** |
| 공개된 연락처 | 아래 문의처 (개인정보처리방침에도 동일 기재) |

## 금지 행위

다음 행위는 신고 대상이며, 확인 시 경고·채팅 제한·계정 정지 등의 조치를 받을 수 있다.

- 욕설·비하·괴롭힘, 특정 개인에 대한 반복적 공격
- 인종·국적·성별·종교·장애 등에 대한 혐오 표현
- 음란물, 성적 괴롭힘
- 스팸, 광고, 반복 도배
- 타인의 개인정보 무단 공개
- 위치 조작(GPS 스푸핑) 등 게임 규칙을 우회하는 어뷰징
- 타인 사칭

국적 기반 팀 대항 게임이라는 특성상 **국적·인종에 대한 혐오 표현을 특히 엄격히 다룬다.**

## 신고

채팅 메시지나 사용자를 신고할 수 있다.

- 신고 시 **해당 메시지 원문이 함께 접수**된다. 팀 채팅은 서버에 저장되지 않으므로, 이 스냅샷이 확인 가능한 유일한 근거다
- 접수된 신고는 순차적으로 검토한다
- 허위·악의적 신고가 반복되면 신고자에게도 조치가 있을 수 있다. 신고에는 도배 방지 제한(1시간당 10건)이 적용된다

## 차단

다른 이용자를 차단하면 **그 사람의 채팅과 위치 공유가 더 이상 전달되지 않는다.**

- 차단은 **단방향**이다. 상대는 차단 사실을 알 수 없고, 팀 채팅에 계속 참여할 수 있다 — 다만 차단한 사람에게는 전달되지 않는다
- 차단 목록은 계정에 저장되어 기기를 바꿔도 유지된다
- 언제든 해제할 수 있다

> 차단은 클라이언트 화면에서 숨기는 방식이 아니라 **서버가 릴레이 대상에서 제외**한다. 차단한 상대의 메시지는 기기에 도달하지도 않는다.

## 조치 기준

| 단계 | 사유 예시 |
|---|---|
| 경고 | 경미한 비방, 1회성 도배 |
| 채팅 제한 | 경고 후 반복, 지속적 도배 |
| 계정 정지 | 혐오 표현, 성적 괴롭힘, 심각한 괴롭힘, 어뷰징 |

## 구현 메모 (개발용)

- 신고 접수: `backend/src/moderation/` — `reports` 테이블. 신고자·피신고자 FK는 `SET NULL`이라 한쪽이 탈퇴해도 접수 기록과 스냅샷이 남는다
- 차단: `user_blocks` 테이블(양쪽 FK `CASCADE`). `ChatGateway`가 릴레이 시 `getBlockedBy(발신자)`로 차단자 소켓을 `.except()`로 제외한다
- 운영자 조치 도구(신고 큐 UI, 정지 처리)는 아직 없다. `reports.status`가 `PENDING`으로 쌓이며, 접수 시 서버 로그에 `신고 접수 #id`로 남는다. v1 이후 관리 도구가 필요하다

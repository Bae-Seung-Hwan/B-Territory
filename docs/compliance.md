# 필요 법적 문서 / 약관 정리

앱스토어·플레이스토어 출시와 전세계 사용자 대상 서비스를 전제로, 어떤 약관·정책 문서가 필요한지 정리한다. 실제 조항 작성은 법률 자문이 필요하며, 이 문서는 "무엇이 왜 필요한지"와 "코드 기준 근거"를 남기는 것이 목적이다.

## 1. 현재 코드 기준 수집 데이터 (2026-07-22 기준)

각 문서에 반영해야 할 실제 수집 항목. 계획만 되어 있고 아직 구현되지 않은 항목은 별도 표기.

| 데이터 | 상태 | 근거 |
|---|---|---|
| 이메일, 닉네임, 국적(팀 배정용) | 구현됨 | `backend/src/users/entities/user.entity.ts` |
| Firebase UID (Firebase Auth 이메일/비밀번호) | 구현됨 | `frontend/src/lib/firebase.ts`, `backend/src/common/firebase/` |
| 포그라운드 GPS 위치 (실시간, 미저장) | 구현됨 — DB에 위치 이력 저장 안 함 | `frontend/src/hooks/use-location.ts` |
| 구역 점령 기록 (스팟ID·팀·유저ID, 좌표 아님) | 구현됨 | `backend/src/claims/entities/*.entity.ts` |
| 카카오맵 WebView 렌더링 (카카오 SDK에 위치 미전달, 지도 렌더용) | 구현됨 | `frontend/src/components/map/KakaoMapView.tsx` |
| 백그라운드 위치 추적 | **미구현** (설계 단계) | `frontend/docs/architecture.md` |
| 사진 촬영/인증 (카메라) | **미구현**, 패키지 미설치 | — |
| 팀 채팅 메시지 저장 | **미구현** (탭 플레이스홀더) | — |
| 푸시 알림 토큰 | **미구현** | — |

→ 백그라운드 위치·사진·채팅이 실제로 구현되는 시점에 아래 문서들의 해당 조항을 반드시 갱신해야 한다.

## 2. 필요 문서 목록

### 2.1 개인정보처리방침 (Privacy Policy) — 필수
- Apple App Store, Google Play 심사 통과에 필수. 앱 내 링크 + 스토어 등록 정보 URL 둘 다 필요.
- 포함해야 할 항목: 수집 항목(위 표 기준), 수집 목적, 제3자 제공(Firebase/Google, 카카오맵), 보관 기간, 해외 이전 고지(전세계 확장 시), 이용자 권리(삭제 요청 등), 아동 개인정보 처리 여부.
- 백그라운드 위치를 실제로 켜는 시점에 Apple은 별도의 정확한 목적 문구(`NSLocationAlwaysAndWhenInUseUsageDescription`)를, Google Play는 "민감한 권한(백그라운드 위치)" 심사 양식 제출을 요구함 — 현재는 포그라운드 권한만 쓰므로 아직 해당 없음.

### 2.2 이용약관 (Terms of Service) — 사실상 표준
- 스토어 필수 항목은 아니지만 사용자 행위 규칙(GPS 스푸핑, 어뷰징 금지 등 게임 특성상 중요), 계정 정지/해지 사유, 콘텐츠 소유권, 면책조항, 서비스 중단 관련 조항 포함.

### 2.3 위치기반서비스 이용약관 + 방송통신위원회 사업자 신고 — 한국 특유 요건
- 한국 위치정보법(위치정보의 보호 및 이용 등에 관한 법률)상, 위치 데이터를 서비스에 이용하면 "위치기반서비스사업자" 신고가 개인정보처리방침과 별개로 필요하고, 전용 약관도 별도로 둬야 함.
- 개인정보처리방침으로 대체되지 않는 별개의 법적 절차이므로 놓치기 쉬움 — 실제 신고 여부는 법률 자문 필요.

### 2.4 커뮤니티 운영정책 — 채팅 기능 구현 시 필요
- 팀 채팅이 낯선 사용자 간 실시간 채팅이므로, Apple 심사 가이드라인(1.2 UGC)을 통과하려면 신고/차단 기능 + 운영정책 명시가 사실상 필수.
- 현재 채팅은 플레이스홀더라 당장은 해당 없음. 채팅 저장/전송 로직 구현 시점에 함께 작성.

### 2.5 최소 연령 정책
- 전세계 대상 확장 시 지역별 기준이 다름: 미국 COPPA(13세), EU GDPR-K(16세, 회원국별 13~16세 조정 가능), 한국 개인정보보호법(14세 미만 법정대리인 동의 필요).
- 가입 연령 하한을 정책적으로 정하고 이용약관·회원가입 플로우에 반영 필요 (현재 `register.tsx`에는 생년월일/연령 확인 필드 없음).

### 2.6 (향후) 결제 관련 약관
- 인앱결제·환불 기능이 생기면 전자상거래 관련 약관, 환불 정책 추가 필요. 현재 결제 기능 없음.
